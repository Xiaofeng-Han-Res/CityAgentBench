# CityAgentBench：深圳城市场景与具身 Agent 评测

[项目页](https://xiaofeng-han-res.github.io/CityAgentBench/) · [English](../README.md) ·
[评测说明](evaluation.md) · [资源下载](resources.md) · [协作开发](../CONTRIBUTING.md)

项目把深圳人才公园、春笋商业街区、春蚕场馆及周边道路组织为可观察、可移动、
可核验任务完成情况的城市场景，研究多模态 Agent 如何理解场景、主动获取信息和完成到达任务。
CityAgentBench 是沿用现有项目页的暂定名称。

## 三个入口的分工

| 入口 | 用途 |
| --- | --- |
| 项目页 | 展示研究目标、场景、方法图和演示视频 |
| GitHub | 项目介绍、代码、环境接口、评测说明、问题跟踪与协作开发 |
| Hugging Face | 版本化题目、题图、场景资源及后续需要分发的大文件 |

## 当前可以使用什么

- 已公开的双语项目页、城市图集和地图演示。
- 35 道历史 L1 题及对应原图的开发预览，用于了解任务和数据格式。
- 评测流程、协作指南、开发路线，以及从试测中提取的参考评分代码。

35 道预览来自 2026-09-28 归档，保留当时的单图、零动作条件，未提供正式测试答案。
当前 L1 已允许移动，L2 必须真实到达；旧预览不能替代 saved193 新场景的验收或正式成绩。
完整 UE 场景、可移植运行器及正式题库仍在整理，因此目前不能承诺下载后直接完成全量评测。

## 如何参与

先阅读[系统结构](architecture.md)和[评测说明](evaluation.md)，再从[开发路线](roadmap.md)
选择一个可验收事项，例如运行环境迁移、L2 路线核验、场景视觉修复、模型接入或结果检查。
在 Issue 中明确场景/协议版本、复现步骤和完成标准；通过分支和 PR 提交修改。

```bash
python3 -B -m unittest discover -s tests -v
```

以上仅运行参考评分检查，不会启动 UE、调用模型或产生 benchmark 成绩。
最新统计见[项目状态](status.md)。场景文件与神经网络权重分别管理，详见[资源说明](resources.md)。
