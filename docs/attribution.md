# Attribution and licensing status

CityAgentBench is the working title for this Shenzhen urban reconstruction and agent
evaluation project. No paper author list, affiliation list, DOI or citation entry is invented
by this repository. Add those when the project owners provide final publication metadata.

[UrbanGround](https://urbanground.github.io/) and its
[repository](https://github.com/UrbanGround/UrbanGround) informed the organization of the
project introduction, environment documentation and evaluation workflow. Its code, data,
performance claims and application packages are not copied into this release.

The existing website was published without selecting a project-wide software or dataset
license. This documentation update does not assign MIT, Apache, Creative Commons or another
license on the owners' behalf. Public availability is not a blanket reuse grant. The project
owners should select terms for code, task text, renders and redistributable scene assets.

Blender, Unreal Engine, plugins, source datasets, textures and other upstream components
retain their applicable terms. Future scene manifests should record provenance and the
license/redistribution basis per component; uploading a scene does not relicense the engine.
