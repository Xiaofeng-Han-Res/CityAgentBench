# Development roadmap

| Priority | Work item | Acceptance evidence |
| --- | --- | --- |
| P0 | Package a portable native environment | Clean-machine startup, fixed scene hash, one verified initial observation |
| P0 | Extract the agent runner and runtime adapter | Configurable paths/model endpoint, one full episode, restored runtime state |
| P0 | Freeze a small L1/L2 development set | Per-task image, start, answer/arrival rules, budgets and human review |
| P0 | Validate L2 routes | Actual walking evidence and measured arrival conditions; blocked routes logged |
| P1 | Finish scene appearance checks | Same-view native glass/grass comparisons and explicit acceptance |
| P1 | Complete the L2 20-task pilot | Frozen selection, first attempts, receipts, denominator and separate technical errors |
| P1 | Review semantic pilot judgments | Independent blind decisions against the frozen rubric |
| P1 | Publish complete HF resource bundles | Dependency closure, checksums, version compatibility and restoration check |
| P1 | Select code/data release licenses | Explicit project-owner decision and third-party attribution |
| P2 | Expand models and task coverage | Matched protocol, fixed split and reproducible batch reports |
| P2 | Validate higher-level tasks | Native scene support, complete routes and task-specific evaluators |

Start with a small complete release. Additional question drafts or screenshots alone do
not satisfy an end-to-end evaluation milestone. Assign ownership through issues; this table
does not invent maintainers or completion dates.
